# InterSim

Project page for the paper *InterSim: Innovative Intersection Digital Twins for Human-in-the-Loop Driving Simulation*
by Luyang Jiang, Chuheng Wei, Yaguang Li, Shaoqi Wang, Yupeng Zhou, Hyunsoo Yun, Xishun Liao, Brandon Pitts, and Ziran Wang.
It is live at <https://purduedigitaltwin.github.io/intersim/>.
